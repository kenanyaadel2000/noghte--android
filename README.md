# Noghte (نقطه) - Zero Trust Security Client

یک کلاینت امنیتی اندروید (Zero Trust) که برای دسترسی کنترل‌شده به منابع و سرویس‌های زیرساختی طراحی شده است. این پروژه به عنوان پروژه پایانی درس مهندسی نرم‌افزار (نرم‌افزار کامپیوتر) توسعه داده شده است.

## ✨ امکانات اصلی (Features)
- **احراز هویت واقعی:** ثبت‌نام و ورود با ایمیل و رمز عبور با استفاده از بک‌اند ابری **Appwrite**.
- **کنترل دسترسی مبتنی بر نقش (RBAC):** سه سطح دسترسی (مدیرعامل، ادمین، ویوور) با سلسله مراتب امنیتی.
- **پنل مدیریت:** مدیریت کاربران، تغییر نقش‌ها و کنترل دسترسی‌ها به صورت داینامیک.
- **دوزبانه (فارسی/انگلیسی):** پشتیبانی کامل از RTL و LTR با قابلیت تغییر زبان در لحظه.
- **تم روشن و تاریک:** با قابلیت تغییر آنی رنگ‌ها و آیکون‌ها.
- **فرآیند تایید ایمیل:** ارسال لینک تایید و مدیریت حساب‌های تایید نشده.
- **ورود مهمان:** امکان مشاهده منابع با دسترسی محدود بدون نیاز به ثبت‌نام.

## 🛠 تکنولوژی‌های استفاده شده (Tech Stack)
- **زبان و UI:** Kotlin, Jetpack Compose, Material 3
- **بک‌اند و دیتابیس (BaaS):** Appwrite Cloud (Auth, Databases)
- **توسعه و بیلد (CI/CD):** GitHub Actions 
- **معماری:** Single Activity, State Hoisting, ViewModel

## 🚀 دانلود و نصب (Download & Install)
برای نصب این پروژه نیازی به کدنویسی یا Android Studio ندارید. 
1. به بخش **Releases** در سمت راست همین صفحه گیت‌هاب بروید.
2. آخرین نسخه (مثلاً `v1.0.0`) را باز کنید.
3. فایل **`app-release.apk`** را دانلود کرده و روی گوشی اندروید خود نصب کنید.

*(نکته برای توسعه‌دهندگان: برای بیلد مجدد، کافیست کد را Push کنید تا GitHub Actions به صورت خودکار نسخه Release را بسازد و منتشر کند).*

## ⚠️ محدودیت‌های نسخه فعلی (Known Limitations)
- **ایمیل تایید:** به دلیل محدودیت‌های پلن رایگان Appwrite، ایمیل‌ها ممکن است در پوشه اسپم بروند یا با تاخیر ارسال شوند. برای ارائه، دسترسی ادمین به عنوان جایگزین در نظر گرفته شده است.
- **لاگ‌ها:** لاگ‌ها در حال حاضر بر اساس اکشن‌های سمت کلاینت ثبت می‌شوند و به صورت Real-time از سرور دریافت نمی‌شوند.
- **احراز هویت دو مرحله‌ای (2FA):** در حال حاضر به صورت شبیه‌سازی شده (UI Mock) است و به سرویس پیامکی یا Authenticator متصل نیست.
